# Class Broadcast

> 新启年工作室 · 基于 ClassIsland 生态的全校多班级广播喊话系统

教师端向多班级批量喊话推送，大屏端接收展示并管理班级分组，双链路传输（局域网直投 + 云端中继），四种独立提醒方式联动 ClassIsland / ClassWidget 展示风格。

## 架构

| 层 | 技术 | 说明 |
|---|---|---|
| 后端 | Rust + Tauri 2 + Tokio | UDP 组播发现、TCP 直投消息、HMAC-SHA256 签名、可选云端中继轮询 |
| 前端 | TypeScript + Vite | 无边框自绘窗口、双角色界面、四种提醒覆盖层 |
| 打包 | NSIS 安装包 | `npm run tauri build` |

## 功能

- **双端合一 - 教师**：批量勾选班级（按分组一键选择）、自定义发送者名称、逐班级送达回执、发送记录
- **双端合一 - 大屏**：班级增删改名、分组 CRUD、四种提醒样式切换预览、收件箱留档
- **提醒样式**：顶部胶囊 / 全屏划入 / CI 接管（ClassIsland 风格）/ CW 接管（ClassWidget 风格）

## 安全设计

- 所有网络包经 **HMAC-SHA256 签名 + ±2 分钟时效校验**，频道密钥仅存两端本地，云端中继无法伪造
- 消息回执确认（ACK），TCP 传输限制包大小，防重放 / 防超大包 / 防伪造
- CSP 限制前端资源来源

## 快速开始

```bash
npm install
npm run tauri dev    # 开发调试
npm run tauri build  # 构建 NSIS 安装包
```

> 首次运行选择角色（教师端 / 大屏端）；两端处于同一校园网时自动发现，**内网开箱即用、无需服务器**。
> 跨网段场景在「设置」中填入中继服务地址即可启用云端链路。

## 协议

端口 `23456/UDP`（大屏 announce 发现，5s 周期）、`23457/TCP`（消息直投 + ACK 回执），可在设置中修改。
